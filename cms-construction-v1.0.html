            How this app looks the way it does

            The skin is sampled from cmsottawa.ca's own design tokens — deep navy #0F1F3D, gold #FFC61A and brand blue #0C98D4 on a near-white ground — so the app feels like the company itself. Headings are set in Georgia, the disclosed stand-in for the site's Playfair Display; body text uses the system sans in place of DM Sans, so the file stays fully self-contained.
